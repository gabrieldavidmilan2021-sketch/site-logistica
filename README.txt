MINHA LOJA - armazenamento somente neste navegador

- O site pode ser publicado gratuitamente no GitHub Pages pelo workflow `.github/workflows/deploy-pages.yml`.
- No GitHub, abra Settings > Pages e selecione GitHub Actions como fonte de publicação. Depois, cada envio para a branch `main` publica o site.
- Vendas, gastos, investimentos, produtos e tarefas são salvos automaticamente no armazenamento local do navegador.
- Os dados ficam somente neste navegador e neste aparelho. Eles não são enviados ao GitHub nem sincronizados com outros dispositivos.
- Se os dados do navegador forem apagados, os registros podem ser perdidos. Use Administração > Baixar backup para guardar uma cópia.
- O backup contém informações financeiras. Não o envie ao GitHub nem o compartilhe publicamente.
- Para usar um backup neste navegador, abra Administração > Restaurar backup e selecione o arquivo JSON.
- GitHub Pages publica uma interface pública. Cada navegador mantém seus próprios dados localmente.
- As páginas de Vendas, Gastos, Investimentos, Lucros, Estoque e Tarefas permanecem disponíveis.
